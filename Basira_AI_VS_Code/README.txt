# Basira AI - VS Code Project

## Project files
- `index.html`: website structure and page content.
- `style.css`: colors, layout, typography, and responsive design.
- `script.js`: form handling, results table, trend summary, and chart drawing.

## How to open the project
1. Extract `Basira_AI_VS_Code.zip`.
2. Open Visual Studio Code.
3. Select **File > Open Folder**.
4. Choose the extracted `Basira_AI_VS_Code` folder.
5. Open `index.html`.
6. Run it in a browser. You can double-click `index.html`, or use the Live Server extension in VS Code.

## Demonstration
1. Open the Dashboard section.
2. Add two or more results for the same indicator using different dates.
3. View the Results History, Trend Summary, and Trend Chart.
4. Select another indicator to view its chart.
5. Use Clear History to reset the demonstration.

## Important project note
This is an educational front-end prototype. It compares entered numbers and displays simple trends. It does not connect to a real AI model, a laboratory, or a database, and it does not provide medical diagnosis. Results are kept in browser memory and are cleared when the page is refreshed or closed.
